# Canon FTb

## 基本参数

| 项目 | 规格 |
|---|---|
| 品牌 | Canon |
| 型号 | FTb |
| 生产年份 | 1971 |
| 画幅 | 135（35mm） |
| 镜头卡口 | Canon FD / FL |
| 快门类型 | 机械横走焦平面快门 |
| 快门速度 | B, 1 — 1/1000 s |
| 测光方式 | TTL CdS 测光（指针式） |
| 电池型号 | PX625（1.35V 水银电池，MR9/LR44 替代） |
| 对焦方式 | 裂像 + 微棱环对焦屏 |

## 型号对比

- 相比 FT：TTL 测光与取景器显示有所改进，是 FT 的改良升级款。
