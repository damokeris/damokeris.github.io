# Nikkormat FT

## 基本参数

| 项目 | 规格 |
|---|---|
| 品牌 | Nikkormat（尼康马特） |
| 型号 | FT |
| 生产年份 | 1965 |
| 画幅 | 135（35mm） |
| 镜头卡口 | Nikon F |
| 快门类型 | 机械横走焦平面快门 |
| 快门速度 | B, 1 — 1/1000 s |
| 测光方式 | TTL 平均测光（CdS，匹配指针） |
| 电池型号 | PX625（1.35V 水银电池，MR9/LR44 替代） |
| 对焦方式 | 裂像 + 微棱环对焦屏 |

## 注意事项

- 全机械快门，无电池也可正常拍摄，仅测光需要电池。
- 测光元件为老式 CdS，年代久远普遍老化，读数不准是常态；测光为收缩光圈测光（stop-down），测光时取景器会变暗；测光不准不影响机械快门使用，可配外置测光表或手机测光代替。
