# Nikon EL2

## 基本参数

| 项目 | 规格 |
|---|---|
| 品牌 | Nikon |
| 型号 | EL2 |
| 生产年份 | 1977 |
| 画幅 | 135（35mm） |
| 镜头卡口 | Nikon F（AI） |
| 快门类型 | 电子控制纵走焦平面快门 |
| 快门速度 | B, 8 — 1/1000 s（自动） |
| 测光方式 | TTL 中央重点测光（SPD） |
| 电池型号 | 2× SR44 / LR44 |
| 对焦方式 | 裂像 + 微棱环对焦屏 |

## 型号对比

- 相比 EL：改挂 Nikon 品牌（不再使用 Nikkormat 名）；支持 AI 卡口镜头；测光元件从 CdS 升级为 SPD。

## 注意事项

- **电子快门相机**：完全依赖电池，装入电池后不通电、快门不释放，几乎就是坏机。
- 电子元件老化后难以修复，收机时务必实测通电与快门动作。
