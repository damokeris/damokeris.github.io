# Nikon EM

## 基本参数

| 项目 | 规格 |
|---|---|
| 品牌 | Nikon |
| 型号 | EM |
| 生产年份 | 1979 |
| 画幅 | 135（35mm） |
| 镜头卡口 | Nikon F（AI） |
| 快门类型 | 电子控制纵走焦平面快门 |
| 快门速度 | 1 — 1/1000 s（自动）、M90 机械档 |
| 测光方式 | TTL 中央重点测光（SPD） |
| 电池型号 | 2× LR44 / SR44 |
| 对焦方式 | 中央裂像对焦屏 |

## 型号对比

- 相比 FM/FE：入门简化版——机身更轻、操作极简，仅有 Auto 档（光圈优先自动）与 M90 机械档，无手动快门档兜底。

## 注意事项

- 尼康面向入门用户的自动曝光机，快门转盘只有 Auto/B/M90 三档，操作极简。
- **只有 A 档（自动）和 M90（机械应急档）两档可用**：如果测光不准，自动档快门就无法正确控制——这类相机测光坏了几乎就是坏机，因为没有手动快门档兜底。
- 电子快门依赖电池，不通电、快门不释放即坏机。
- M90 为唯一机械应急档，仅能固定 1/90 s 快门，测光失效后基本失去使用价值。
