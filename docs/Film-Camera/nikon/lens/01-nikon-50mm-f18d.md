# Nikon AF Nikkor 50mm f/1.8D

## 基本参数

| 项目 | 规格 |
|---|---|
| 品牌 | Nikon |
| 型号 | AF Nikkor 50mm f/1.8D |
| 卡口 | Nikon F（AI-S / D 型） |
| 焦距 | 50mm |
| 最大光圈 | f/1.8 |
| 最小光圈 | f/22 |
| 镜头结构 | 5 组 6 片 |
| 最近对焦距离 | 0.45m |
| 最大放大倍率 | 0.15x（1:6.6） |

| 滤镜口径 | 52mm |
| 尺寸 | 63.5 × 39mm |
| 重量 | 约 155g |

## 详细信息

- 因价格低廉、光学素质出色，被摄影圈戏称为“人类光学精华”（简称“人光精”）。
- 经典的尼康标准镜头，画质与体积平衡出色，是入门与日常最实用的一支。
- D 型触点传递距离信息，支持 3D 矩阵测光。
- 对焦由机身马达驱动（无内置马达），搭配 FM3A、F100 等机身使用。
