# Nikkormat FT2

## 基本参数

| 项目 | 规格 |
|---|---|
| 品牌 | Nikkormat（尼康马特） |
| 型号 | FT2 |
| 生产年份 | 1975 |
| 画幅 | 135（35mm） |
| 镜头卡口 | Nikon F（非 AI） |
| 快门类型 | 机械横走焦平面快门 |
| 快门速度 | B, 1 — 1/1000 s |
| 测光方式 | TTL 中央重点测光（CdS） |
| 电池型号 | PX625（1.35V 水银电池，MR9/LR44 替代） |
| 对焦方式 | 裂像 + 微棱环对焦屏 |

## 型号对比

- 相比 FTN：快门速度拨盘移至顶盖，取景器内可直接读取快门速度；新增闪光热靴。

## 注意事项

- FTN 的改进版，增加了闪光同步热靴。
- 全机械快门，无电池可正常拍摄。
- CdS 测光普遍老化，读数不准是常态；不影响机械快门使用。
