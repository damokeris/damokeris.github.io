# Nikon FM2

## 基本参数

| 项目 | 规格 |
|---|---|
| 品牌 | Nikon |
| 型号 | FM2 |
| 生产年份 | 1982 |
| 画幅 | 135（35mm） |
| 镜头卡口 | Nikon F（AI-S） |
| 快门类型 | 机械横走焦平面快门（钛帘/铝帘） |
| 快门速度 | B, 1 — 1/4000 s |
| 测光方式 | TTL 中央重点测光（SPD） |
| 电池型号 | 2× LR44 / SR44 |
| 对焦方式 | 裂像 + 微棱环对焦屏 |

## 型号对比

- 相比 FM：最高快门从 1/1000s 提升至 1/4000s；闪光同步提升至 1/200s；早期版本采用钛蜂窝快门帘。

## 注意事项

- 尼康机械相机的巅峰之作，1/4000 s 机械快门，无电池可完全正常拍摄。
- 可靠性极高，二手市场最保值的尼康机械机身之一。
- 测光仅作参考，测光不准不影响拍摄——这也是它比电子机身耐用的根本原因。
- 钛帘版（早期）快门帘比后期铝帘版更轻更耐用，收机时可留意区分。
