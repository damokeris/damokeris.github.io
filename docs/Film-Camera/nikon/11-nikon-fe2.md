# Nikon FE2

## 基本参数

| 项目 | 规格 |
|---|---|
| 品牌 | Nikon |
| 型号 | FE2 |
| 生产年份 | 1983 |
| 画幅 | 135（35mm） |
| 镜头卡口 | Nikon F（AI-S） |
| 快门类型 | 电子控制纵走焦平面快门（钛帘） |
| 快门速度 | B, 8 — 1/4000 s（自动） |
| 测光方式 | TTL 中央重点测光（SPD） |
| 电池型号 | 2× LR44 / SR44 |
| 对焦方式 | 裂像 + 微棱环对焦屏 |

## 型号对比

- 相比 FE：最高快门从 1/1000s 提升至 1/4000s；闪光同步从 1/125s 提升至 1/250s。

## 注意事项

- FE 的改进版，快门速度提升至 1/4000 s，配备钛帘。
- **电子快门相机**：完全依赖电池，装入电池后不通电、快门不释放，几乎就是坏机。
- 电子元件老化后难以修复，收机时务必实测：装电池、过片、各档快门是否动作。
- 无电池时仅有 M250 机械应急档可释放快门，其余档位均需电池。
