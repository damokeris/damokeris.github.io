# Nikkormat FT3

## 基本参数

| 项目 | 规格 |
|---|---|
| 品牌 | Nikkormat（尼康马特） |
| 型号 | FT3 |
| 生产年份 | 1977 |
| 画幅 | 135（35mm） |
| 镜头卡口 | Nikon F（AI） |
| 快门类型 | 机械横走焦平面快门 |
| 快门速度 | B, 1 — 1/1000 s |
| 测光方式 | TTL 中央重点测光（CdS） |
| 电池型号 | PX625（1.35V 水银电池，MR9/LR44 替代） |
| 对焦方式 | 裂像 + 微棱环对焦屏 |

## 型号对比

- 相比 FT2：改用 AI 卡口，配合 AI 镜头可实现全开光圈测光。

## 注意事项

- 尼康马特系列的最后一款，是 FT2 的收尾版本。
- 全机械快门，无电池可正常拍摄。
- CdS 测光普遍老化，读数不准不影响机械快门使用。
