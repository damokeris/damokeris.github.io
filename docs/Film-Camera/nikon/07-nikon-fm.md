# Nikon FM

## 基本参数

| 项目 | 规格 |
|---|---|
| 品牌 | Nikon |
| 型号 | FM |
| 生产年份 | 1977 |
| 画幅 | 135（35mm） |
| 镜头卡口 | Nikon F（AI） |
| 快门类型 | 机械横走焦平面快门 |
| 快门速度 | B, 1 — 1/1000 s |
| 测光方式 | TTL 中央重点测光（SPD） |
| 电池型号 | 2× LR44 / SR44 |
| 对焦方式 | 裂像 + 微棱环对焦屏 |

## 温馨提示

**对焦屏**
- 可更换：标配 K 型（裂像 + 微棱环），可换 B 型（全磨砂）、E 型（网格）等。
- 更换需拆取景器组件，建议送维修店操作。

**电池**
- 使用 2× LR44 / SR44，随处可买，无替代焦虑。
- 建议用 SR44（氧化银）：电压稳定，测光准确。
- 用 LR44（碱性）也能跑，但电压随电量下降，测光读数会逐渐偏移；长期不用时取出电池，防止漏液腐蚀。

## 注意事项

- 尼康紧凑型机械相机经典之作，与 FE（电子版）同期推出。
- 全机械快门，无电池可正常拍摄，可靠性高，是二手市场最耐用的尼康机身之一。
- 测光元件 SPD 相对耐用，但年代久远仍可能漂移；测光不准不影响机械快门使用。
