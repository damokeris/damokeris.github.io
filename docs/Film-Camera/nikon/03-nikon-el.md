# Nikkormat EL

## 基本参数

| 项目 | 规格 |
|---|---|
| 品牌 | Nikkormat（尼康马特） |
| 型号 | EL |
| 生产年份 | 1972 |
| 画幅 | 135（35mm） |
| 镜头卡口 | Nikon F（非 AI） |
| 快门类型 | 电子控制纵走焦平面快门 |
| 快门速度 | B, 4 — 1/1000 s（自动） |
| 测光方式 | TTL 中央重点测光（CdS） |
| 电池型号 | PX625（1.35V 水银电池，MR9/LR44 替代） |
| 对焦方式 | 裂像 + 微棱环对焦屏 |

## 型号对比

- 相比同代 FT 系列（机械快门）：尼康马特首款电子快门机型，主打光圈优先自动曝光，与机械款同期并存。

## 注意事项

- **电子快门相机**：完全依赖电池供电，现在如果装入电池后不通电、快门不释放，几乎就是坏机——电子元件老化后难以修复。
- 水银电池已停产，需用 MR9 转接环 + LR44 替代，电压不同可能影响测光精度和快门精度。
- 测光不准时：电子快门机身若无外置机械快门档兜底，实用性大打折扣。
