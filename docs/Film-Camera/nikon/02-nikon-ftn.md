# Nikkormat FTN

## 基本参数

| 项目 | 规格 |
|---|---|
| 品牌 | Nikkormat（尼康马特） |
| 型号 | FTN |
| 生产年份 | 1967 |
| 画幅 | 135（35mm） |
| 镜头卡口 | Nikon F |
| 快门类型 | 机械横走焦平面快门 |
| 快门速度 | B, 1 — 1/1000 s |
| 测光方式 | TTL 中央重点测光（CdS） |
| 电池型号 | PX625（1.35V 水银电池，MR9/LR44 替代） |
| 对焦方式 | 裂像 + 微棱环对焦屏 |

## 型号对比

- 相比 FT：测光从全画面平均改为 60/40 中央重点，读数更精准。

## 注意事项

- FT 的测光改进版，主要改进是中央重点测光。
- 全机械快门，无电池可正常拍摄。
- CdS 测光元件普遍老化，测光不准不影响机械快门使用，可外置测光替代。
